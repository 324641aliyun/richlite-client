# richlite-client
我的世界.cc 服务器 RichLite 客户端发布：Windows / macOS / Linux / Android 启动器导入包、校验文件和安装说明。

公开说明更新：2026-11-02T07:32:00+09:00（Asia/Tokyo）。

下载请前往 [RichLite 0.3.1 发布页](https://github.com/324641aliyun/richlite-client/releases/tag/v0.3.1)。ZIP 由 GitHub Releases 提供，玩家下载不经过官网笔记本。请选择 Desktop 或 Android 文件，并核对同名 `.sha256` 校验文件。

- **Windows / macOS / Linux**：使用 [官方 HMCL](https://hmcl.huangyuhui.net/) 导入 Desktop ZIP，新建独立实例。由启动器安装对应系统及 CPU 架构的 Java 21、Minecraft 1.21.1 和 NeoForge 21.1.251。
- **Android**：使用 [官方 Zalith Launcher 2](https://github.com/ZalithLauncher/ZalithLauncher2/releases) 导入 Android ZIP。关闭桌面光影、降低视距，具体渲染器支持依设备 GPU 和驱动而定。
- 账户管理添加 LittleSkin 外置认证：`https://littleskin.cn/api/yggdrasil`。登录自己的账号并选择角色，确认角色已加入本服白名单。
- 游戏入口：`s.我的世界.cc`；备用 ASCII：`s.xn--rhqx00c95nv9a.cc`。无需填写端口。
- 官网：[我的世界.cc](https://xn--rhqx00c95nv9a.cc)。每日维护为 03:40–05:30 Asia/Tokyo（UTC+09:00），资源检查通过后恢复。

0.3.1 为跨平台导入候选发布：打包、CRC 和逐文件 SHA256 已核查；新导入包尚未在四个平台全部实机启动。macOS、Linux 和 Android 的实际运行、驱动适配与进服仍需设备测试。已有 Windows 0.3.0 客户端具有真实公网进服记录，玩法版本与服务器保持兼容。
